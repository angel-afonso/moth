Moth for Windows
================

Open Moth: run moth.exe from this folder. It needs nothing else installed; tabs run
PowerShell (PowerShell 7 if it's installed). To use another shell, set "shell" in the
settings, e.g. "cmd.exe" or "wsl.exe" (Open Settings in the command palette, Ctrl+Shift+P).

The download isn't code-signed, so SmartScreen may warn the first time: choose
"More info" → "Run anyway".

Settings live in %APPDATA%\moth (config.json, themes, hosts.json, the session) and the
log in %LOCALAPPDATA%\moth\logs\moth.log.
